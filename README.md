# 牛马赎身计算器

独立网页：[打开计算器](https://yingyinyin666.github.io/retirement-calculator/)

填写两人合计的可用资产、每年储蓄、男方当前年龄、两人完全退休时男方年龄，以及退休后的分项支出，查看退休资金需求、缺口和逐年收支。可选填男方和女方各自的养老金年领取额、起领年龄，以及退休后额外年收入；填女方养老金时还需填女方当前年龄。计算在浏览器本地进行；页面不上传或保存输入。

这是固定收益率和固定通胀率的情景计算，不代表未来收益或退休成功概率。原项目：[《高性价比人生指南》](https://github.com/yingyinyin666/HowToLiveBetter)。
